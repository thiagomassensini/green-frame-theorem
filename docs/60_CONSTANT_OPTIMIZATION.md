# Constant optimization

The kernel release favors a transparent conservative bound. The paper proof obtains the better constant by separating current, parent, and grandparent contributions and summing the `b⁻²` and `b⁻³` tails.

Possible later refinements include weighted Young inequalities, a Schur estimate on the infinite Gram operator, use of the true carry activities rather than `ω≤1`, and a depth-one/bulk decomposition. None changes the lower frame mechanism supplied by the residual channel.

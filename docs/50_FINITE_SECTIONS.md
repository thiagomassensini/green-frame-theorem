# Finite sections and limits

The frame ledger is uniform in an arbitrary section index. Therefore every cutoff satisfying the same hypotheses inherits the same lower and upper constants.

The limit module records the closed-interval transport needed by strong-limit arguments: if every scalar section value lies in a fixed closed interval and the sequence converges, its limit lies in the same interval.

The full operator convergence proof and the canonical infinite carry construction remain documented in the paper specification and are not replaced by numerical convergence claims.
